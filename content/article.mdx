## What this drop is

X published a public folder of code. In that folder’s own words, it is the core code that decides which posts a viewer sees in the For You feed. That is a statement about this folder. It is not a promise that you can turn on X’s live feed from your laptop.

How to read this page. Every gray box is a quote from a file in that public folder. The small line under it is the file name, line numbers, and the exact commit we copied from. If a sentence cannot point at a box, it does not belong on this page.

## How a post is found

A post has to be found before it can be scored. The files describe two pools: posts from accounts a viewer follows, and posts from accounts they do not.

## What can hide or cover it

A found and scored post can still be hidden, or left in the list with a cover on top. The files name those answers as allow, cover, or drop.

<EvidenceBlock
  id="visibility-rules"
  headline="The published hide-and-show rules run in a fixed order"
  prose="The README says the first rule that answers drop stops the rest. A second set of rules applies only when the post is a recommendation from an account the viewer does not follow, and those rules can only drop. Both lists are in visibility-filtering/rules/registry.rs. You can read that order. You cannot launch the live filter service from this drop."
  need="The rule file is listed in evaluation order, as the README states."
